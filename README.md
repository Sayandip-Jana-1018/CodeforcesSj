## What's inside

Each day brings one unsolved problem from the Codeforces problemset, picked by rating band and rotated across tags. Each folder holds:

- `solution.java`: the accepted solution, with fast I/O
- `README.md`: intuition, approach, time/space complexity, edge cases, brute force → optimal, and the verdict
